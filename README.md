# Custom Store Backend (TypeScript + Express + Prisma + SQLite + Swagger)

### Быстрый старт:
1. Установи зависимости:
   ```bash
   npm install
   ```
2. Создай базу данных SQLite:
   ```bash
   npx prisma db push
   ```
3. Запусти сервер в режиме разработки:
   ```bash
   npm run dev
   ```
4. Открой Swagger UI в браузере:
   **http://localhost:5000/swagger**
